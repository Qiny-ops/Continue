## 一、数据库概述

### 1.1 数据库选型

| 环境 | 数据库 | 说明 |
|------|--------|------|
| 开发环境 | SQLite | 轻量级，零配置，便于开发调试 |
| 生产环境 | PostgreSQL | 功能强大，性能优秀，支持高并发 |

### 1.2 命名规范

| 规则 | 说明 |
|------|------|
| 表名 | 小写字母，下划线分隔，复数形式 |
| 字段名 | 小写字母，下划线分隔 |
| 主键 | id |
| 外键 | 关联表名单数_id |
| 索引 | idx_表名_字段名 |
| 唯一索引 | uq_表名_字段名 |

### 1.3 表清单

| 序号 | 表名 | 说明 |
|------|------|------|
| 1 | users | 用户表 |
| 2 | roles | 角色表 |
| 3 | permissions | 权限表 |
| 4 | roles_permissions | 角色-权限关联表 |
| 5 | projects | 项目表 |
| 6 | project_members | 项目成员表 |
| 7 | testcase_repository | 用例库表 |
| 8 | testcase_version | 版本表 |
| 9 | test_module | 测试模块表 |
| 10 | test_case | 测试用例表 |
| 11 | test_step | 测试步骤表 |
| 12 | testcase_review | 用例评审表 |
| 13 | testcase_execution | 用例执行记录表 |

## 三、数据表详细设计

### 3.1 用户表 (users)

**表名**: `users`

**说明**: 存储系统用户信息

| 字段名 | 数据类型 | 可空 | 默认值 | 说明 |
|--------|----------|------|--------|------|
| id | INTEGER | 否 | 自增 | 主键 |
| username | VARCHAR(150) | 否 | - | 用户名，唯一 |
| password | VARCHAR(128) | 否 | - | 密码（加密存储） |
| email | VARCHAR(254) | 否 | - | 邮箱，唯一 |
| name | VARCHAR(100) | 否 | - | 用户姓名 |
| phone | VARCHAR(20) | 是 | NULL | 手机号码 |
| avatar | VARCHAR(255) | 是 | NULL | 头像URL |
| title | VARCHAR(100) | 是 | NULL | 职位/头衔 |
| system_role_id | INTEGER | 是 | NULL | 系统角色ID，外键关联roles.id |
| status | VARCHAR(20) | 否 | 'active' | 用户状态 |
| last_login_time | DATETIME | 是 | NULL | 最后登录时间 |
| last_login_ip | VARCHAR(45) | 是 | NULL | 最后登录IP |
| reset_password_token | VARCHAR(64) | 是 | NULL | 重置密码令牌 |
| reset_password_expire | DATETIME | 是 | NULL | 重置密码令牌过期时间 |
| created_at | DATETIME | 否 | 当前时间 | 创建时间 |
| updated_at | DATETIME | 否 | 当前时间 | 更新时间 |

**索引**:

| 索引名 | 字段 | 类型 |
|--------|------|------|
| PRIMARY | id | 主键 |
| uq_users_username | username | 唯一索引 |
| uq_users_email | email | 唯一索引 |
| idx_users_system_role | system_role_id | 普通索引 |

**状态枚举**:

| 值 | 说明 |
|------|------|
| active | 活跃 |
| disabled | 禁用 |
| suspended | 暂停 |
| pending | 待激活 |

## 五、数据库优化建议

### 5.1 索引优化

- 为高频查询字段添加索引
- 为外键字段添加索引
- 为组合查询条件添加复合索引
- 避免过多索引影响写入性能

### 5.2 查询优化

- 使用 `select_related` 优化外键查询
- 使用 `prefetch_related` 优化多对多查询
- 避免 N+1 查询问题
- 合理使用分页
