## 文档概要

### 1. 需求文档 (requirements.md)

- 项目背景与目标
- 功能需求（用户管理、项目管理、测试用例管理等）
- 非功能需求（性能、安全、可用性）
- 验收标准
- 术语表

### 2. 架构设计文档 (architecture.md)

- 系统整体架构图
- 前端架构（Vue 3 + Pinia + Vue Router）
- 后端架构（Django + DRF）
- 数据架构
- 安全架构
- 部署架构

### 3. 开发文档 (development.md)

- 开发环境搭建
- 项目结构详解
- 前端开发指南
- 后端开发指南
- 认证与授权
- 测试指南
- 常见问题

### 4. 接口文档 (api.md)

- 用户认证接口（登录、注册、密码重置）
- 项目管理接口（CRUD、成员管理）
- 测试用例接口（用例库、版本、模块、用例）
- 评审与执行接口
- 枚举值说明
- 错误码说明

### 5. 数据库设计文档 (database.md)

- 数据库选型与命名规范
- ER 图
- 13 张数据表详细设计
- 索引设计
- 数据迁移
- 优化建议

### 6. 部署文档 (deployment.md)

- 部署架构
- 环境准备
- 后端部署（Gunicorn + Systemd）
- 前端部署（静态文件）
- Nginx 配置
- SSL 证书
- 监控与日志
- 备份策略
- 更新与回滚

## 技术栈

### 前端

| 技术 | 版本 | 说明 |
|------|------|------|
| Vue | 3.5.x | 前端框架 |
| Pinia | 3.x | 状态管理 |
| Vue Router | 5.x | 路由管理 |
| Element Plus | 2.x | UI 组件库 |
| Axios | 1.x | HTTP 客户端 |
| Vite | 7.x | 构建工具 |

### 后端

| 技术 | 版本 | 说明 |
|------|------|------|
| Django | 5.x | Web 框架 |
| Django REST Framework | - | API 框架 |
| JWT | - | 身份认证 |
| PostgreSQL | 13+ | 生产数据库 |
| SQLite | - | 开发数据库 |
