AI驱动接口自动化流程分析

一、整体架构

基于 Flask + JSON-RPC 2.0 + SSE 流式传输 构建的5阶段流水线式AI驱动API测试系统

核心数据流：知识库接口文档 → AI生成用例 → AI分析依赖 → AI填充数据 → 执行测试 → AI校验结果

二、五阶段详细流程

阶段1：testcase.generate — 生成测试用例

入口：core/engine.py:ApiTestEngine.generate_testcase()

1. 加载提示词模板，按边界值、等价类、安全测试等维度设计用例

2. 创建知识库会话，通过RAG关联接口文档进行流式问答

3. 流式返回并累积AI结果，解析为结构化JSON测试用例

4. 可选将用例存入MySQL，销毁知识库会话

关键点：依托RAG知识库+接口文档生成用例，避免AI幻觉，保证用例真实可用

阶段2：dependency.get — 分析接口依赖

入口：core/engine.py:ApiTestEngine.get_api_dependency()

1. 加载提示词，注入已有测试用例信息

2. AI结合接口文档自动分析前置依赖接口与执行顺序

3. 输出有序 run_list（接口地址、请求方法、请求体模板）

4. 内置JSON清洗 + 3次重试容错机制

关键点：自动识别登录、鉴权等前置接口，完成链路编排

阶段3：testdata.fill — 填充测试数据

入口：core/engine.py:ApiTestEngine.fill_test_data()

1. 注入依赖链路、基础地址、业务测试数据

2. AI区分正向/逆向/边界场景，自动填充合法/异常测试数据

3. 自动拼接完整请求URL，输出全量可执行请求参数

关键点：智能场景化造数，替代人工编写测试数据

阶段4：testcase.execute — 执行测试（核心智能化环节）

入口：execute/engine.py:TestExecutionEngine.execute_testcase()

1. 基于 requests.Session 管理会话与Cookie

2. 按顺序遍历接口链路：首接口直接执行，后续接口由AI动态提取上游响应数据填充参数

3. SSE流式返回状态码、响应体、耗时等信息

4. 接口执行失败立即终止流程，输出执行摘要

关键点：运行时动态透传Token、业务ID等依赖数据，完美模拟手工测试逻辑

阶段5：testcase.validate — 校验结果

入口：execute/engine.py:TestExecutionEngine.validate_testcase()

1. 注入预期结果 + 实际执行结果，交由AI校验

2. 校验维度：HTTP状态码、业务code、关键字段、跨接口数据一致性、错误信息

3. 输出最终结果：是否通过 + 详细原因

三、核心架构特点

特点 实现方式
AI贯穿全流程 各阶段均采用提示词模板+LLM调用，AI为核心驱动力
RAG知识库 前3阶段对接知识库服务，LLM引用真实接口文档，杜绝幻觉
流式传输 SSE流式响应，前端实时展示AI思考与执行进度
会话隔离 每次AI调用创建独立知识库会话，使用后销毁
参数动态注入 执行阶段AI根据历史响应实时填充下游接口参数
JSON解析容错 支持代码块提取、内容清洗、多次重试，兼容LLM不规则输出
MCP协议 可作为MCP Server对外暴露，对接上层调度框架

四、整体数据流

用户输入(kb_id, query)
    ↓
阶段1 生成用例  ←  RAG问答  ←  接口文档知识库
    ↓
阶段2 分析依赖  ←  RAG问答  ←  接口文档知识库
    ↓
阶段3 填充数据  ←  RAG问答  ←  接口文档知识库
    ↓
阶段4 执行测试  ←  LLM动态提取上游数据
    ↓
阶段5 结果校验  ←  LLM综合分析
    ↓
输出最终测试报告

五、设计决策、亮点与待优化点

优秀设计亮点

1. 采用RAG知识库绑定接口文档，AI输出严格基于真实业务，有效规避大模型幻觉；

2. 执行阶段运行时动态参数注入，解决复杂接口链路数据依赖痛点；

3. 全流程提示词模板化，解耦易维护、便于迭代调优；

4. 会话隔离、JSON容错、SSE流式输出，兼顾稳定性与前端交互体验。

现存待优化点

1. 长接口链路下，频繁创建/销毁知识库会话，存在性能损耗；

2. LLM输出格式不稳定，依赖大量容错逻辑，仍存在解析风险；

3. 缺少会话复用、结果缓存机制，长任务执行效率可进一步提升。

六、总结

本系统将传统接口自动化从「人工编写脚本、静态编排」升级为AI全链路智能化测试，依靠RAG保证业务准确性，依靠动态参数传递解决链式接口依赖，是一套落地性极强的大模型赋能自动化测试解决方案。
