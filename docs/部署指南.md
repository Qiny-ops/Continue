## 二、环境准备

### 2.1 系统更新

```bash
# Ubuntu
sudo apt update && sudo apt upgrade -y

# CentOS
sudo yum update -y
```

### 2.2 安装基础软件

```bash
# Ubuntu
sudo apt install -y python3 python3-pip python3-venv \
    nodejs npm nginx postgresql postgresql-contrib \
    git curl wget

# CentOS
sudo yum install -y python3 python3-pip \
    nodejs npm nginx postgresql postgresql-server \
    git curl wget
```

### 2.3 安装 pnpm

```bash
npm install -g pnpm
```

### 2.4 配置 PostgreSQL

```bash
# 启动 PostgreSQL
sudo systemctl start postgresql
sudo systemctl enable postgresql

# 创建数据库和用户
sudo -u postgres psql

# 在 psql 中执行
CREATE DATABASE testcase_db;
CREATE USER testcase_user WITH PASSWORD 'your_password';
ALTER ROLE testcase_user SET client_encoding TO 'utf8';
ALTER ROLE testcase_user SET default_transaction_isolation TO 'read committed';
ALTER ROLE testcase_user SET timezone TO 'Asia/Shanghai';
GRANT ALL PRIVILEGES ON DATABASE testcase_db TO testcase_user;
\q
```

## 三、后端部署

### 3.1 创建应用目录

```bash
sudo mkdir -p /var/www/testcase
sudo chown -R $USER:$USER /var/www/testcase
cd /var/www/testcase
```

### 3.2 克隆代码

```bash
git clone <repository-url> .
```

### 3.3 创建虚拟环境

```bash
cd /var/www/testcase/Testbackend
python3 -m venv venv
source venv/bin/activate
```

### 3.4 安装依赖

```bash
pip install --upgrade pip
pip install django djangorestframework django-cors-headers django-filter pyjwt requests gunicorn psycopg2-binary
```

### 3.5 配置环境变量

创建 `.env` 文件：

```bash
# /var/www/testcase/Testbackend/.env
DJANGO_SECRET_KEY=your-super-secret-key-here
DJANGO_DEBUG=False
DJANGO_ALLOWED_HOSTS=yourdomain.com,www.yourdomain.com

# Database
DB_NAME=testcase_db
DB_USER=testcase_user
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432

# JWT
JWT_SECRET=your-jwt-secret-key
JWT_EXPIRATION_HOURS=24
```

### 3.6 修改 Django 配置

编辑 `Testbackend/settings.py`：

```python
import os
from dotenv import load_dotenv

load_dotenv()

SECRET_KEY = os.environ.get('DJANGO_SECRET_KEY')
DEBUG = os.environ.get('DJANGO_DEBUG', 'False') == 'True'
ALLOWED_HOSTS = os.environ.get('DJANGO_ALLOWED_HOSTS', '').split(',')

DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': os.environ.get('DB_NAME'),
        'USER': os.environ.get('DB_USER'),
        'PASSWORD': os.environ.get('DB_PASSWORD'),
        'HOST': os.environ.get('DB_HOST'),
        'PORT': os.environ.get('DB_PORT'),
    }
}

STATIC_ROOT = os.path.join(BASE_DIR, 'staticfiles')
```

### 3.7 数据库迁移

```bash
python manage.py makemigrations
python manage.py migrate
python manage.py collectstatic
```

### 3.8 创建超级用户

```bash
python manage.py createsuperuser
```

### 3.9 配置 Gunicorn

创建 Gunicorn 配置文件：

```bash
# /var/www/testcase/Testbackend/gunicorn_config.py
bind = "127.0.0.1:8000"
workers = 4
worker_class = "sync"
timeout = 120
keepalive = 5
errorlog = "/var/log/testcase/gunicorn_error.log"
accesslog = "/var/log/testcase/gunicorn_access.log"
loglevel = "info"
```

创建日志目录：

```bash
sudo mkdir -p /var/log/testcase
sudo chown -R $USER:$USER /var/log/testcase
```

### 3.10 创建 Systemd 服务

```bash
sudo nano /etc/systemd/system/testcase.service
```

内容：

```ini
[Unit]
Description=TestCase Management System
After=network.target

[Service]
User=www-data
Group=www-data
WorkingDirectory=/var/www/testcase/Testbackend
Environment="PATH=/var/www/testcase/Testbackend/venv/bin"
ExecStart=/var/www/testcase/Testbackend/venv/bin/gunicorn \
    --config gunicorn_config.py \
    Testbackend.wsgi:application
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
sudo systemctl daemon-reload
sudo systemctl start testcase
sudo systemctl enable testcase
sudo systemctl status testcase
```

## 五、Nginx 配置

### 5.1 创建 Nginx 配置

```bash
sudo nano /etc/nginx/sites-available/testcase
```

内容：

```nginx
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;

    # 重定向到 HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name yourdomain.com www.yourdomain.com;

    # SSL 证书配置
    ssl_certificate /etc/letsencrypt/live/yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/yourdomain.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # 前端静态文件
    location / {
        root /var/www/testcase/frontend;
        index index.html;
        try_files $uri $uri/ /index.html;
        
        # 缓存静态资源
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
            expires 1y;
            add_header Cache-Control "public, immutable";
        }
    }

    # API 代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 静态文件
    location /static/ {
        alias /var/www/testcase/Testbackend/staticfiles/;
        expires 1y;
        add_header Cache-Control "public";
    }

    # 日志
    access_log /var/log/nginx/testcase_access.log;
    error_log /var/log/nginx/testcase_error.log;
}
```

### 5.2 启用配置

```bash
sudo ln -s /etc/nginx/sites-available/testcase /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

## 九、备份策略

### 9.1 数据库备份

创建备份脚本：

```bash
sudo nano /usr/local/bin/backup_testcase.sh
```

内容：

```bash
#!/bin/bash
BACKUP_DIR="/var/backups/testcase"
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="$BACKUP_DIR/testcase_db_$DATE.sql.gz"

mkdir -p $BACKUP_DIR

pg_dump -U testcase_user testcase_db | gzip > $BACKUP_FILE

# 删除 7 天前的备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +7 -delete

echo "Backup completed: $BACKUP_FILE"
```

设置定时任务：

```bash
sudo chmod +x /usr/local/bin/backup_testcase.sh
sudo crontab -e

# 每天凌晨 2 点执行备份
0 2 * * * /usr/local/bin/backup_testcase.sh >> /var/log/testcase/backup.log 2>&1
```

### 9.2 代码备份

```bash
# 备份整个应用目录
tar -czf /var/backups/testcase_app_$(date +%Y%m%d).tar.gz /var/www/testcase
```

## 十、更新部署

### 10.1 更新流程

```bash
# 1. 进入项目目录
cd /var/www/testcase

# 2. 拉取最新代码
git pull origin main

# 3. 更新后端
cd Testbackend
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py collectstatic --noinput

# 4. 更新前端
cd ../vue3-frontend
pnpm install
pnpm build
sudo cp -r dist/* /var/www/testcase/frontend/

# 5. 重启服务
sudo systemctl restart testcase
sudo systemctl restart nginx
```

### 10.2 回滚流程

```bash
# 1. 回滚代码
git checkout <previous-commit>

# 2. 重新部署
# 按照更新流程重新执行

# 3. 恢复数据库（如需要）
gunzip -c /var/backups/testcase/testcase_db_xxx.sql.gz | psql -U testcase_user testcase_db
```

## 十一、常见问题

### 11.1 服务无法启动

```bash
# 检查日志
sudo journalctl -u testcase -n 50

# 检查端口占用
sudo netstat -tlnp | grep 8000

# 检查权限
ls -la /var/www/testcase
```

### 11.2 数据库连接失败

```bash
# 检查 PostgreSQL 状态
sudo systemctl status postgresql

# 测试连接
psql -U testcase_user -d testcase_db -h localhost

# 检查配置
sudo -u postgres psql -c "SHOW listen_addresses;"
```

### 11.3 Nginx 502 错误

```bash
# 检查后端服务
sudo systemctl status testcase

# 检查 SELinux (CentOS)
sudo setsebool -P httpd_can_network_connect 1

# 检查 Nginx 配置
sudo nginx -t
```

### 11.4 静态文件 404

```bash
# 收集静态文件
python manage.py collectstatic

# 检查权限
sudo chown -R www-data:www-data /var/www/testcase/Testbackend/staticfiles
```

## 十二、性能优化

### 12.1 Gunicorn 优化

```python
# gunicorn_config.py
workers = (CPU核心数 * 2) + 1
worker_class = "gevent"
worker_connections = 1000
threads = 2
```

```nginx
# /etc/nginx/nginx.conf
worker_processes auto;
worker_connections 1024;
keepalive_timeout 65;
gzip on;

```
