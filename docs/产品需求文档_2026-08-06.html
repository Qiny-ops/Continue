1. 产品概述

TestFlow 是一个 AI 增强的软件测试管理平台，覆盖从需求提取、测试用例设计、接口测试执行到质量评审的完整测试生命周期。核心能力：

  • AI 原生：知识库驱动的测试用例自动生成、接口依赖分析、测试数据填充、执行结果校验
  • 多项目协作：项目级 RBAC 权限、成员管理、数据隔离
  • 完整测试链：需求管理 → 用例设计 → 用例评审 → 接口执行 → 结果校验
  • 双引擎架构：AI 推理引擎（用例生成）+ 接口测试引擎（执行/校验），通过 MCP 协议供 AI Agent 调用

3. 安全架构

3.1 认证体系

机制实现
JWT 认证自定义 JWTAuthentication（djangorestframework-simplejwt）
Token 刷新过期前 5 分钟自动刷新（前端去重并发）
Token 黑名单登出立即失效（数据库存储 jti）
CORS 白名单get_safe_cors_origin() 统一校验（禁止反射 Origin）
内部服务认证X-Internal-API-Key 头 + 环境变量对比
API Key 鉴权微服务 X-API-Key 头（dev 模式可跳过）
密码加密Django PBKDF2 + 重置用加密签名 Token
限流按 IP 限流（生产 60次/分）+ AI 生成限流（10-20次/时）

3.2 授权层级

系统级：system_admin > 系统权限(9种) > 普通用户 │ 项目级：Owner > Admin > 自定义角色(12种权限) > 成员 > 游客 │ 数据级：项目成员自动可见依赖项目的用例库/版本/模块/用例/需求/接口测试

3.3 安全防护

HSTS + 安全 Cookie（生产环境强制 HTTPS）
CSRF 保护（非流式视图） + 凭据遮蔽（审计日志）
SSRF 防护（拦截 169.254.169.254 / 内网 / loopback）
文件上传白名单（32 种扩展名 + 50MB 上限）
管理员凭据不入 LLM 提示词（占位符本地解析）
SECRET_KEY 强制生产环境覆盖（开发回退拦截）
密码强度强制（大小写+数字+黑名单）
登录防枚举（静默返回不暴露用户是否存在）
